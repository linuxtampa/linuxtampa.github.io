I help businesses ship and run software on open source stacks—websites, backends, cloud, Linux, and the APIs that tie them together. That includes practical AI automation and coding agents where they actually speed delivery, not where they just add risk.

Websites

Design, build, and improve sites that are fast, accessible, and easy to maintain—from a fresh build to incremental fixes on what you already have, with coding agents in the loop for scaffolding, refactors, and review when they earn their keep.

  • GoTonight.com — live music event search engine covering multiple Florida markets; sole developer and operator for 15+ years (ColdFusion/Java, MSSQL, jQuery; fuzzy event/artist dedup; layered anti-abuse and Google Maps geocoding)
  • WordPress site for professional musician Justin Nurin

Backend systems

Design and implement APIs, databases, and server-side logic that stay performant and maintainable as the product grows—including agent-assisted migrations and test generation when the codebase is too large to touch by hand alone, and programmatic AI usage wired into the application itself (APIs, workers, and tools that call models as part of the product).

  • Migrated legacy TypeScript, Golang, and Java codebases at Amazon Robotics (AWS CDK)
  • Zero-downtime infrastructure deployments and RDS upgrades that improved throughput while cutting cost

Cloud & automation

Architecture, IaC, and CI/CD on AWS, GCP, or Azure—automation and hosting sized to the workload, plus AI-driven ops helpers (runbook agents, change summaries, pipeline triage) where they reduce toil without hiding failure modes.

  • Built Matter Foundations, McKinsey’s internal cloud tooling for customer transformation engagements
  • Cloud apps and CI/CD for payment processors and federal agencies on AWS GovCloud
  • Repeatable pipelines for clients including AQR Capital, 3M, Refinitiv/ThomsonReuters, and a confidential defense company
  • Introduced Jenkins CI/CD at Syniverse for internal test environments

Linux administration

Setup, hardening, and day-to-day ops so Linux servers stay reliable, secure, and tuned for the work they run—with selective automation and agents for repetitive admin tasks, never as a substitute for understanding the box.

  • Defense-sector hardening: STIG implementation and FIPS 140-3 alignment
  • Automated PKI / Certificate Authority for certificate lifecycle management
  • 30+ years of Linux admin—from embedded systems (including the world’s first Linux-based ATM) to enterprise cloud

API integration

Connect systems with clear, documented integrations—auth, data mapping, and reliable service-to-service communication, including wiring coding agents and automation workflows to the APIs your business already depends on.

  • REST APIs and integrations for telecom, cloud apps, and financial clearing
  • SS7 and ANSI-41 work for cellular carriers, plus modern cloud API development
